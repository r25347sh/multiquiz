# ドイツ語単語 MultiQuiz 問題集

## 構成

| レベル | ファイル数 | 問題数 |
|--------|------------|--------|
| 超初級 (ultra_beginner) | 4 | 30×2 + 50×2 |
| 初級 (beginner) | 10 | 30×5 + 50×5 |
| 中級 (intermediate) | 10 | 30×5 + 50×5 |
| プレ上級 (pre_advanced) | 4 | 30×2 + 50×2 |
| 上級 (advanced) | 4 | 30×2 + 50×2 |
| マニアック (maniac_*) | 10 | 場面別 |

## マニアック場面

- restaurant / travel / medical / office / academic

## 使い方

1. [multiquiz.html](../../multiquiz.html) を開く
2. `.multiquiz` または `.mq` をドラッグ＆ドロップ
3. または raw URL から読み込み

## 機能

- `shuffle_questions` / `shuffle_options` 有効
- 4択 single、解説付き
- 全機能サンプル: `../samples/all_features_sample.multiquiz`
